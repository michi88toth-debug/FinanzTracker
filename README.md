# FinanzTracker Android

Erste Android-Build-Basis für FinanzTracker. Sie öffnet die vorhandene HTML-Oberfläche lokal in einer Android-WebView und enthält einen GitHub-Actions-Workflow für eine Debug-APK.

Bitte zuerst `ANLEITUNG_DE.txt` lesen.

**Hinweis:** Dies ist Quellcode, keine geprüfte APK. Direkte Google-Drive-/OneDrive-Integration und automatische Cloud-Synchronisierung sind noch nicht enthalten. Die Datenspeicherung und Exporte müssen auf dem Gerät getestet werden.
